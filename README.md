# Elevate Physio

A responsive physiotherapy clinic website built with React and Vite. Includes clinic information, services, editable demo team and testimonials, a contact/map section, and an appointment form that opens WhatsApp with a pre-filled request.

## Getting started

```sh
npm install
npm run dev
```

Create a production build with `npm run build`, or preview it locally with `npm run preview`.

## Clinic configuration

Update contact details, WhatsApp number, address, map links, hours, and social URLs in `src/data/clinicData.js`. Replace the clearly labeled demo team profiles and testimonials with approved clinic content before publishing. The appointment form requires a WhatsApp number in international format without a leading `+`.

The site uses Google Fonts and remote Unsplash images; an internet connection is needed to load these assets.
